# Phase 5 SEO audit

## Baseline

Read-only HTTP and Playwright inspection covered the staged storefront, the production hostname and a local Next.js production build on November 24, 2026. The local build uses Next.js 16.4.6, React 19, strict TypeScript, Tailwind 4, Radix/shadcn components, Sanity/next-sanity, Stripe, Neon/Drizzle and React Email. The application calls Resend over HTTP for email. Twilio environment placeholders exist, and the repository has no active SMS transport. No orders, payments or messages were created during the audit.

No sourdough loaf or recipe detail was discovered through initial homepage and recipe links. Later published sitemap QA confirmed three active specialty or classic loaf URLs. ## Browser baseline

Single unthrottled Chromium runs with an iPhone 13 viewport and GA network requests blocked. Figures vary with local networking, cache state and machine load. LCP and TTFB are lab milliseconds. Payloads are resource transfer sizes and reflect each navigation, including cache effects. CLS and observed long-task blocking were zero on the sampled pages. This run does not measure field INP or establish Core Web Vitals compliance.

| Page             | Staging LCP / TTFB | Local LCP / TTFB | Staging image / JS transfer |
| ---------------- | ------------------ | ---------------- | --------------------------- |
| Home             | 944 / 110          | 1,972 / 874      | 780 / 482 KB                |
| Pickup           | 684 / 104          | 444 / 397        | 0 / 461 KB                  |
| Recipes          | 680 / 20           | 632 / 599        | 0 / 461 KB                  |
| Pesto Mozzarella | 936 / 22           | 1,152 / 504      | 402 / 475 KB                |

Fonts transferred about 83 KB per sampled navigation. Lora and the existing Barlow Condensed fallback use font swapping. Balgin assets remain pending. No horizontal overflow or failed rendered images were observed on the four sampled pages. The homepage hero was preloaded. GA loads in the storefront layout, while payment scripting is introduced in the payment workflow. Cart-related JS is present on editorial pages for the shared bag. Photo replacement and post-launch field measurement are the next performance priorities.

See the [implementation inventory](seo-implementation.md) and the [launch checklist](seo-launch-checklist.md) for follow-up verification.

The linked Vercel project reports authentication on deployments other than custom domains. Its domain lookup returned 404 for the apex. The firewall configuration read was denied, so the active custom firewall and verified bot policies still need an owner’s check. Staging returned HTTP 200 to OAI-SearchBot and PerplexityBot user-agent probes, providing evidence for that public URL only.

## After implementation

The same unthrottled mobile Chromium setup produced the following local production-build timings. This is a single comparative lab sample. Replacing placeholder imagery and monitoring field performance are the remaining priorities.

| Page             | Baseline LCP / TTFB | Updated LCP / TTFB | Updated image / JS transfer |
| ---------------- | ------------------- | ------------------ | --------------------------- |
| Home             | 1,972 / 874         | 1,380 / 434        | 866 / 472 KB                |
| Pickup           | 444 / 397           | 368 / 330          | 0 / 456 KB                  |
| Recipes          | 632 / 599           | 552 / 518          | 0 / 456 KB                  |
| Pesto Mozzarella | 1,152 / 504         | 444 / 380          | 468 / 469 KB                |

Observed CLS was zero across all four URLs. The homepage incurred 1 ms of observed long-task blocking and the other sampled pages recorded zero. JavaScript transfer and fonts were broadly stable, and the homepage hero `sizes` now matches the actual layout. Measured homepage image transfer fell from 914 KB to 866 KB in the local comparison. No sampled page had horizontal overflow or a failed rendered image. The 1200 × 630 branded fallback avoids a dependency on unapproved photography. These samples leave INP and other field metrics unverified.

Axe scans across 13 public URLs initially reported an announcement outside landmarks and insufficient contrast for the special-order step numbers. The announcement now uses a named landmark and the numbers use a darker existing palette mix. The pass after fixes reported zero violations for the tested WCAG 2.0/2.1 AA and best-practice rule sets. Interactive states and assistive-technology testing remain broader than this automated sample.

The staged homepage's outbound anchors pointed to the official Instagram profile and four posts or reels. The baseline raw HTML links to About, Pickup, Special Orders, Storage + Reheating, legal pages and initially visible products. The Recipes landing page was orphaned in those sampled links. It has a sitemap entry after indexing approval and can gain a crawlable footer link when the bakery publishes content. Product pages with related recipes also link back to the collection using the existing CMS label.
